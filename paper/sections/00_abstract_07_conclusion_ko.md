# 초록·하이라이트·키워드·결론 (한글 검토용 — 영문판과 1:1 대응)

## 초록

diffusion inpainting으로 만든 합성 이미지는 객체 탐지 학습 데이터를 저비용
으로 늘릴 수 있지만, 실용적 질문 하나가 열려 있다: 생성 이미지의 예산이
고정되어 있을 때, 어느 클래스가 그것을 받아야 하는가? **인공지능 측
기여**는 이 배분 질문에 대한 통제된 답이다. 우리는 배분 신호 — 빈도로
정의한 tail 집합 대 측정된 클래스별 average precision으로 선택한 난이도
정의 weak 집합 — 를 집합 내 가중(uniform 대 우선순위 가중)과 교차하되
예산·클래스 수·생성기·프롬프트·규칙 기반 품질 검증을 고정하고, 그 결과
네 증강 arm을 사전 등록·해시 동결된 contrast, seed-blocked 검정, 다중비교
보정으로 평가한다. **공학 응용**은 운용상 상이한 두 체제의 군용 항공기
탐지다: 43클래스 지상 자연 시점 벤치마크와 20클래스 위성 시점 벤치마크를
각각 소형 1-stage 검출기와 대형 사전학습 transformer 검출기로 학습한다.
세 결과가 따른다. 첫째, 배분 신호가 이득의 위치를 결정한다: 각 arm은
자기가 겨냥한 클래스를 개선하며(set×scope 상호작용 +0.06, 보정
p = 0.017; 위성 벤치마크에서 +0.05로 재현), 가중 축은 네 비교 전부에서
null이다. 둘째, 더 강한 검출기 — 비증강 baseline이 최고 증강 소형 모델을
앞선다 — 아래에서는 모든 증강 이득이 사라진다. 셋째, 무비용 repeat-factor
재표집은 깊은 불균형 벤치마크에서 생성을 압도하지만 얕은 벤치마크에서는
null이고, 그곳에서는 inpainting이 유의한 이득을 내는 유일한 증강이다.
이 발견들은
3단계 엔지니어링 규칙을 준다 — 검출기 headroom을 확인하고, 무료 재표집으로
탐침한 뒤, 측정된 최약 클래스에 균등 분할로 생성하라. 코드, 생성 이미지
pool, 모든 학습 산출물을 공개할 예정이다.

## 하이라이트

- 이득의 위치를 정하는 것은 클래스 집합 선택이지 클래스별 가중이 아니다
- set×scope 상호작용 +0.06(보정 p=0.017), 위성 영상에서 재현
- 더 강한 사전학습 검출기 아래에서는 모든 증강 이득이 사라진다
- 재표집은 깊은 불균형에서 이기고 얕은 곳에서 실패 — 저렴한 진단 탐침
- 사전 등록 contrast와 seed-blocked 통계가 증강 주장을 지킨다

## 키워드

Data augmentation; Diffusion inpainting; Object detection; Class
imbalance; Synthetic data allocation; Military aircraft detection

# 7. 결론

우리는 생성 증강 문헌이 암묵에 부치는 질문을 물었다: 합성 이미지 예산이
고정되어 있을 때, 어느 클래스가 그것을 받아야 하는가? 배분 신호와 집합 내
가중에 대한 2×2 요인 설계 — 고정된 예산·생성기·검증 프로토콜 아래, 두
공개 군용 항공기 벤치마크와 두 검출기 계열에서 실행 — 가 일관된 답을
준다. **중요한 결정은 클래스 집합이다**: 이득은 겨냥한 집합에 떨어지며,
이는 자연 시점 벤치마크의 사전 등록 상호작용으로 확인되고 위성 시점
벤치마크에서 효과 크기로 재현된다. 반면 고른 집합 안에서 예산을 균등으로
나누든 우선순위로 나누든 측정 가능한 차이가 없다. 신호의 선택은 사소하지
않다 — 여기서 빈도와 측정 난이도는 서로소인 클래스를 고르기 때문이다.
worst-case 클래스 성능이 목표인 실무자는 가장 희소한 클래스가 아니라
측정된 최약 클래스를 겨냥해야 한다. 그러나 두 발견 모두 조건부다: 대형
사전학습 transformer 검출기 아래에서는 모든 증강 효과가 사라지고, 깊은
불균형에서 생성을 압도하던 무비용 재표집 baseline은 불균형이 얕아지면
null — 국소적으로는 해로움 — 로 바뀐다. 그 결과인 결정 규칙 — headroom을
평가하고, 무료 재표집으로 탐침하고, 측정된 약점에 균등 분할로 생성하라 —
은 즉시 실행 가능하며, 그것을 만들어 낸 평가 프로토콜(예산 통제, 사전 등록
contrast, seed-blocked 검정)은 증강 주장이 제기되는 어디서든 재사용
가능하다. 요인 설계를 강한 검출기로 확장하는 것, 예산 스케일링 곡선을
그리는 것, 재표집과 표적 생성이 합성되는지 검정하는 것이 자연스러운 다음
단계다.
