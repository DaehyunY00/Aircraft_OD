# 5. 결과 (한글 검토용 — 영문판 05_results.md v3와 1:1 대응)

모든 결과는 4절의 군용 항공기 탐지 셀에 대해, test split의 mAP50–95 —
IoU(intersection over union) 임계 0.50–0.95에 걸친 mean average precision —
로 보고하며, 독립 학습 seed 3개의 평균과 seed 간 표준편차를 제시한다.
이득(Δ)은 항상 같은 셀의 `basic_aug` baseline 대비다. 사전 등록된
contrast(3.6절)는 seed-blocked paired t-검정, 95% 신뢰구간(CI), 셀별
5-contrast family 내 Holm 보정으로 평가하고, seed 평균 클래스별 AP에 대한
Wilcoxon signed-rank 검정을 보조 증거로 쓴다. 표 2가 4개 셀의 마스터 결과,
표 3이 사전 등록 contrast 결과다.

## 5.1 배분 신호가 이득의 위치를 결정한다

**빈도와 난이도는 서로 다른 클래스를 고른다.** MAD에서 클래스별 학습
인스턴스 수와 baseline test AP는 *음의* 상관을 보인다(mAP50–95 기준;
Pearson r = −0.375, p = 0.013; Spearman ρ = −0.408, p = 0.007). AP50
기준으로 보면, 가장 희소한 클래스(YF-23, 학습 인스턴스 97개)가 최고
점수(0.93)를 기록하는 반면, 가장 약한 클래스(Rafale 0.31, F-14 0.37)는
빈도상 medium~head 구간에 있다. 경험적으로, 빈도 정의 tail 집합과 AP 정의
weak 집합은 MAD에서 서로소이고(중첩 0/13) MAR20에서는 소형 검출기 기준 1개
클래스만 겹친다(4.1절). 이것이 2×2 배분 설계를 유의미하게 만드는 전제다 —
빈도가 난이도의 좋은 대리지표였다면 두 신호는 같은 클래스를 골라 해리시킬
수 없었을 것이다.

**이득은 겨냥한 집합에 떨어진다 (MAD, 확인 실험).** 그림 3(왼쪽)은 MAD ×
YOLOv8n의 결과를 이중 해리로 보여준다: 각 집합 계열은 자기 표적 scope를
상대 계열보다 훨씬 크게 개선하고, 그 역도 성립한다. seed 평균으로
tail-집합 두 arm은 tail scope를 +0.061 개선했지만 weak scope는 +0.019만
개선했고, weak-집합 두 arm은 정확히 거울상(weak +0.040, tail +0.022)
이었다. 사전 등록된 set×scope 상호작용 — 두 집합 계열의 격차가 두 scope
사이에서 벌어지는 정도 — 은 **+0.0598 (95% CI [0.045, 0.075], Holm 보정
p = 0.017)**이며, 세 seed 모두 같은 방향이었다. 클래스 수준에서도 이득은
소수 집중이 아니라 넓게 퍼졌다: tail-uniform arm에서 tail 13개 중 11개
개선(최대 Tu-95 +0.169, MiG-31 +0.101), weak-uniform arm에서 weak 13개 중
11개 개선(최대 Tornado +0.123, 데이터셋 최약 클래스인 Rafale +0.086).

**해리는 위성 도메인(MAR20)에서 재현된다.** 그림 3(오른쪽)은 MAR20 ×
YOLOv8n의 동일 분석이다. 상호작용 추정치는 **+0.0523**(95% CI [0.021,
0.083]; 세 seed 모두 양수)으로 MAD 추정치의 95% CI 안에 들어오며,
tail-표적 arm은 역시 tail scope에서 최대 이득(selective +0.044; 클래스
단위 Wilcoxon p = 0.031 — n = 6에서 도달 가능한 최솟값), weak-표적
arm들은 weak scope에서 최대 이득(+0.030~+0.034)을 보였다. 다만 MAR20의
scope는 각 6클래스뿐이라 seed-blocked 검정의 검정력이 낮고, 상호작용은
Holm 보정을 넘지 못한다(비보정 p = 0.018, Holm p = 0.091). 따라서
MAR20은 두 번째 확인 결과가 아니라 **효과 크기의 독립 재현**으로 보고한다.

**집합 내 가중은 이득의 증거를 보이지 않는다.** 클래스 집합의 선택과 달리,
고른 집합 *안에서* 고정 예산을 어떻게 나누는지는 어느 조건에서도 이득의
증거를 보이지 않았다: weighted 대 uniform contrast는 사전 등록된 4개 비교
전부에서 null이었고 추정치는 0 근처에 중심을 둔다(MAD +0.002, p = 0.81 /
−0.012, p = 0.17; MAR20 +0.014, p = 0.11 / +0.004, p = 0.52; 표 3). CI가
양방향의 작은 효과를 배제하지는 못하므로 엄밀한 동등성을 주장하지 않는다 —
데이터가 배제하는 것은 집합 선택 효과에 견줄 만한 크기의 집합 내 가중
이득이다. uniform과 weighted arm이 클래스 집합·생성기·프롬프트·품질 검증·
예산을 전부 공유하므로, 연구한 예산 범위에서 작동 변수는 배분의
*신호*(어느 클래스인가)이지 배분의 *형태*(클래스당 몇 장인가)가 아니라고
결론한다.

**표적 이득에는 더 작은 전역 spillover가 동반된다.** 한 집합을 증강하면
그 밖에서도 일관되지만 더 작은 이득이 났다: MAD에서 tail-uniform arm이
weak scope를 +0.031 개선했고(클래스 단위 p = 0.002), MAR20의 교차 집합
이득은 +0.004~+0.013 범위였다. 따라서 배경 inpainting은 집합 특이적 표적
성분과 더 작은 도메인 전역 성분의 합으로 보이며, 이는 6절에서 논의하는
recall 중심 기제와 부합한다.

## 5.2 강한 사전학습 검출기는 모든 증강 이득을 지운다

소형 검출기를 RT-DETR-L로 바꾸면(4.2절) baseline이 MAD 0.575→0.869,
MAR20 0.572→0.697로 뛰고 — 우리가 측정한 모든 증강 효과가 사라진다
(그림 4, 표 2). MAD에서 모든 Δ는 0 이하였다: uniform −0.004, selective
−0.001, RFS **−0.016**; tail scope의 통합 inpainting-대-baseline
contrast는 −0.008(p = 0.36)이다. MAR20에서도 같은 패턴이 반복됐다
(uniform −0.007, selective −0.005, RFS +0.003; 통합 tail contrast
+0.004, p = 0.72). 특히 강한 검출기의 *baseline* 자체가 최고 증강
YOLOv8n 결과를 큰 폭으로 웃돈다(MAD 0.869 대 0.661).

두 가지 관찰이 따른다. 첫째, 이 연구에서 증강 이득은 검출기의 headroom에
조건부다: 모델에 남은 headroom이 거의 없으면 재표집도 생성 증강도 측정
가능한 가치를 더하지 못하며, 가장 큰 단일 지렛대는 검출기 업그레이드
자체다(셀 간 비교; 6.1절). 둘째, 강한 검출기 아래에서 유일하게 일관된
*음수* Δ는 MAD의 RFS였다(세 scope 모두 −0.016 수준) — 용량과 사전학습이
이미 충분할 때 중복 노출 증가는 가볍게 해로울 수 있음을 시사하지만,
기제를 주장하지 않고 관찰로 보고한다. RT-DETR-L 셀은 축소 설계(baseline,
RFS, tail-집합 2 arm)라 상호작용 검정은 불가하며, "이득 소멸" 주장은
측정된 모든 arm의 Δ≈0에 근거한다.

## 5.3 재표집의 유효성은 불균형 구조에 달려 있다

MAD에서 모든 diffusion arm을 압도했던 무비용 재표집 기준선 RFS(+0.086
all, +0.098 tail, +0.117 weak; 클래스 단위 p ≤ 2×10⁻⁴)는 MAR20으로
이전되지 않았다. 같은 검출기·같은 프로토콜에서 MAR20의 RFS는 +0.003
(all), +0.016 (tail), **−0.011 (weak; 클래스 단위 p = 0.031)** —
YOLOv8n 아래에서 관찰된 유일한 통계적으로 유의한 음수 효과다. MAD는
43클래스에 걸친 깊은 불균형(최대/최소 인스턴스 비 10.5)이라 희소 클래스
이미지의 재노출이 추가 학습 신호를 갖지만, MAR20의 20클래스 분포는
상대적으로 얕아 이미 본 이미지의 추가 노출은 보태는 것이 적고, 진짜
새로운 배경 변이를 주입하는 inpainting은 유효하게 남는다(5.1절). 실제로
MAR20에서 통계적으로 유의한 이득을 낸 증강은 inpainting뿐이었다. 실무적
함의는 6절에서 전개한다: RFS는 보편적 승자가 아니라 저렴한 1차 시도이며,
그 실패는 생성 증강이 비용값을 하는 국면의 진단 신호다.

## 5.4 강건성 점검

**생성 품질은 해리를 설명하지 못한다.** 처음 생성된 MAD의 3개 pool은
규칙 기반 품질 검증을 비슷한 비율로 통과했고(79–82%), 네 번째 pool도 같은
기준으로 할당량을 채웠다. pool별 FID(Fréchet inception distance)와 CLIP
기반 이미지–텍스트 유사도 점수도 동등했으며, FID가 *가장 나쁜*
pool(weakness)이 weak scope의 유의 이득을 냈다 — 품질 차이는 이득의
위치를 설명할 수 없다. MAR20의 검증 실패율은 0.6%였고 4개 pool 모두
500장 예산을 채웠다.

**환각 객체는 MAD의 RFS 격차를 설명하지 못한다.** 검출기 기반 감사에서
MAD 합성 배경의 10.2%에 라벨 없는 항공기가 환각돼 있었다. object-level
gate로 해당 이미지를 전부 제거하고 원래 3개 diffusion arm을 재학습해도
all scope 성능 변화는 최대 |Δ| ≤ 0.017(9개 비교 전부 비유의,
p = 0.11–0.97)이었고, RFS 우위는 사실상 그대로였다(RFS 대비 Δ = −0.055 ~
−0.067, p < 10⁻⁴). 생성 아티팩트발 라벨 노이즈는 해리도 재표집 격차도
설명하지 않는다.
